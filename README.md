\# 🚀 NexaForge



\### 💡 Connect. Collaborate. Create. Build Your Developer Journey.



\*\*NexaForge\*\* is a Java-based collaborative project platform designed to bring developers together. It provides a space where developers can discover one another, showcase projects, build teams, connect through follows, and collaborate on innovative ideas.



\---



\## 🌟 About the Project



NexaForge aims to create a collaborative developer community where people can:



\- 👨‍💻 Discover developers with different technical skills.

\- 🚀 Showcase and explore innovative projects.

\- 🤝 Connect with other developers.

\- 👥 Build teams and collaborate on projects.

\- 📩 Send and manage project join requests.

\- 🔔 Receive notifications and stay updated.

\- 👤 Manage personal developer profiles.



\## ✨ Key Features



| Feature | Description |

|---|---|

| 🔐 User Authentication | User registration and login |

| 👤 Developer Profiles | Manage and showcase developer information |

| 🔍 Developer Search | Discover other developers |

| 🤝 Follow System | Follow developers and manage connections |

| 👥 Team Collaboration | Connect with project teams |

\## ⚙️ Installation \& Setup



\### 1. Clone the Repository



```bash

git clone https://github.com/Monalisakabi/NexaForge.git

```



\### 2. Navigate to the Project



```bash

cd NexaForge

```



\### 3. Configure the Database



\- Install and start MySQL.

\- Create a database named `projecthub`.

\- Configure the database connection in `hibernate.cfg.xml`.

\- Provide the database username and password through a secure configuration mechanism.



\### 4. Open the Project



Import the project into IntelliJ IDEA, Eclipse, or Spring Tool Suite as a Maven project.



\### 5. Build the Project



```bash

mvn clean install

```



\### 6. Run the Application



Deploy the generated WAR file to a compatible servlet container, such as Apache Tomcat.
